## Requisitos

Para rodar o projeto é necessário ter instalado na sua máquina:

* [Node.js 22.13.0](https://nodejs.org/pt/download)
* [MongoDB](https://www.mongodb.com/docs/manual/administration/install-community/)


## Funcionamento

Crie no Mongo uma database com o nome **_"silabas_a"_** e uma collection com nome **_"silabas_jogos"_**, importe o arquivo **_"silabas_a.silabas_jogos.json"_** na collection:

Depois abra a pasta e execute os comandos:

```
npm init -y
```

```
npm install express
```

```
npm install cors
```

```
npm install mongodb
```

e depois rode o o codigo com:

```
node server.js
```
